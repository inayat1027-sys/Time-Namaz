# Время Намаза — Android приложение

Cordova-приложение с локальными уведомлениями о времени намаза и нативным виджетом главного экрана.

## Что внутри

- **www/index.html** — ваш HTML-интерфейс (исправлен код уведомлений)
- **config.xml** — конфигурация Cordova (плагины, разрешения, иконки)
- **android-widget/** — исходники нативного Android-виджета (Java + XML)
- **hooks/install-widget.js** — скрипт, который подключает виджет к Android-проекту
- **.github/workflows/build-apk.yml** — GitHub Actions, собирающий APK автоматически
- **res/icon/android/** — иконки приложения всех размеров

## Как собрать APK (рекомендуемый способ — GitHub Actions)

### Шаг 1. Создайте репозиторий на GitHub
1. Зайдите на https://github.com и создайте новый пустой репозиторий (Private или Public — без разницы).
2. Назовите его, например, `vremya-namaza`.

### Шаг 2. Залейте этот проект в репозиторий

**Вариант A — через сайт (без командной строки):**
1. На странице нового репозитория нажмите **"uploading an existing file"**.
2. Перетащите ВСЕ файлы и папки из этой папки (`prayer-app`) в окно загрузки.
3. Нажмите **Commit changes**.

**Вариант B — через командную строку:**
```bash
cd prayer-app
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/vremya-namaza.git
git push -u origin main
```

### Шаг 3. Дождитесь сборки и скачайте APK
1. После загрузки откройте вкладку **Actions** в репозитории.
2. Увидите запущенный workflow **"Build Android APK"**. Ждите ~5-8 минут.
3. Когда сборка станет зелёной (✅), кликните по ней.
4. Внизу страницы — раздел **Artifacts**, в нём файл **VremyaNamaza-debug-apk**.
5. Скачайте zip, разархивируйте → внутри `.apk` файл.

### Шаг 4. Установите APK на телефон
1. Перенесите `.apk` на телефон (через USB, Telegram, Google Drive — как угодно).
2. На телефоне разрешите установку из неизвестных источников (**Настройки → Безопасность**).
3. Откройте файл и установите.

### Шаг 5. Настройка после установки (ВАЖНО для уведомлений!)
Чтобы уведомления приходили даже когда приложение закрыто:
1. Откройте приложение → разрешите уведомления когда система спросит.
2. **Настройки телефона → Приложения → Время Намаза → Батарея → Не оптимизировать** (отключить экономию).
3. На Xiaomi/Huawei/Oppo дополнительно: **Автозапуск → Разрешить**.
4. Загрузите Excel-файл с расписанием — уведомления зарегистрируются автоматически.

### Шаг 6. Добавьте виджет на главный экран
1. Долгое нажатие на свободное место рабочего стола → **Виджеты**.
2. Найдите **Время Намаза** в списке.
3. Перетащите на главный экран.

## Локальная сборка (если хотите без GitHub)

Требования: Node.js 20+, Java JDK 17, Android Studio с SDK 34.

```bash
npm install -g cordova
cd prayer-app
cordova platform add android
cordova build android --debug
```

APK будет здесь: `platforms/android/app/build/outputs/apk/debug/app-debug.apk`

## Что было исправлено в коде уведомлений

1. **Добавлен канал уведомлений** `prayer_channel` — на Android 8+ без канала уведомления вообще не показываются.
2. **`androidAllowWhileIdle: true`** — пробивает Doze-режим, благодаря чему уведомления приходят даже когда телефон спит.
3. **`priority: 2` + `wakeup: true`** — высокий приоритет, всплывающее уведомление со звуком.
4. **Разрешения в манифесте**: `POST_NOTIFICATIONS` (Android 13+), `SCHEDULE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED` — чтобы расписание восстанавливалось после перезагрузки телефона.
5. Убран дубликат функции `sendTestNotification`.
6. Уведомления переустанавливаются при запуске приложения (`deviceready`) — на случай если ОС сбросила расписание.

Сейчас собирается **debug APK** — его можно установить на телефон, но в Google Play загрузить нельзя. Для релизной подписанной версии нужен keystore. Если понадобится — скажите, добавлю release-workflow с подписью.
